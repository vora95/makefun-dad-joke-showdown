A small program that writes one short text (124 characters) to `/output/entry.txt`: a single original dad joke — a father offers to teach his son to drive, and reassures the scared boy that he'll be right there, braking for effect.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
